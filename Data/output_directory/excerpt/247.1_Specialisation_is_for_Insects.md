247.1: Specialisation is for Insects

translation of this Tumblr post by user yoricklike, which quotes and interpolates Robert A Heinlein.

Val an human savir un babe refassar con vruglet, un envajon vellisquar, un porc flejovar, un vascel gournar,
A human being should be able to change a diaper, plan an invasion, butcher a hog, conn a ship,

un edifiç orðenjar, un vintedos scaur, accont balançar, un mur costroir,
design a building, write a sonnet, balance accounts, build a wall,

un os algebrar, y morent consolar, commant acceptar, commant assignar,
set a bone, comfort the dying, take orders, give orders,

un bougr favuar fin ag sounç,
suck a fellow off to completion,

collaborar, agir soul, equaçon souvr, un novel problem indagar,
cooperate, act alone, solve equations, analyse a new problem,

feyen yettar, un augrimour instroir, un repasc ragostant cocinar, combattr cos expedið, morir braf.
pitch manure, program a computer, cook a tasty meal, fight efficiently, die gallantly.

Y sparteç cadarar incombisc for a insegt.
Specialisation is for insects.
